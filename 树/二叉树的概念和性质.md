  
# 概念
每个结点最多两个子树

满二叉树：除叶子结点外，每个结点都有两个孩子，并且所有的叶子结点都在最后一层

完全二叉树：把**满二叉树**从1开始编号，严格按照从上到下，从左到右依次编号，然后按照编号从大到小删除若干个结点，**剩余部分**称为完全二叉树，**满二叉树也是完全二叉树**

# 性质
假设某二叉树不是空树，有n(n>=1) 个结点，根结点是第1层，一共有h层

### 1.在第i层上最多（满二叉树）有$2^{i-1}$个结点

### 2.深度为h的二叉树，最少有h个结点（斜树），最多有$2^h-1$个结点（满二叉树）

**证明**：$1+2^1+2^2+2^3+……+2^{h-1}=2^h-1$

### 3.具有n个结点的 完全二叉树 ，其高度(层数)为$ceil(log(n+1))$ (ceil向上取整) ，或者$floor(log(n))+1$  (floor向下取整)
**证明一**：
假设完全二叉树有h层，有n个结点，则$$2^{h-1}-1<n\le 2^h-1$$
等于$$2^{h-1}<n+1\le 2^h$$
等于$$h-1<log(n+1)\le h$$
所以$$h=ceil(log(n+1))$$
**证明二**：
$$2^{h-1}-1<n\le2^h-1$$

等于$$2^{h-1}\le n<2^h$$
等于$$h-1\le log(n)<h$$
所以$$h=floor(log(n))+1$$

*！！！注意：计算机log底数默认为 2*

### 4.  二叉树 中，**叶子结点**的个数比**度为2的结点**的个数多一个

假如 二叉树中有n个结点，其中度为0的结点(叶子结点)有n0个，度为1的结点有你n1个，度为2的结点有n2个，有：$$n0=n2+1$$
**证明**：$$n=n0+n1+n2$$
$$n-1=0*n0+1*n1+2*n2=n1+2*n2$$
*n个结点的树一共有n-1条边，分别为度为0的分出一条，度为1的分出1条，度为2的分出2条*

所以$$n0+n1+n2-1=n1+2*n2$$
所以$$n0=n2+1$$

### 5.把 完全二叉树 从1开始编号，按照从上到下，从左到右的顺序标号，第i号结点，其父亲是i/2，其左孩子是2i，其右孩子是2i+1
