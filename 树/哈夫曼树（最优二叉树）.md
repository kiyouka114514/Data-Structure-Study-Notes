# 概念

结点的路径长度：从根结点到该结点的路径上所经过的**边数**
树的路径长度：**叶子结点**的路径长度之和

*注意！有些资料有歧义：
叶子结点的路径长度之和：外路径长度
所有结点的路径长度之和：路径长度*

结点的带权路径长度：给树中每一个结点加一个权值，该结点的路径长度 * 该结点的权值
树的带权路径长度（WPL）：所有**叶子结点**的**带权**路径长度之和

哈夫曼树/最优二叉树：
给定n个**带权值**的结点，这n个结点全部做**叶子结点**，去构造一棵二叉树，其中**WPL值最小**的，称为哈夫曼树/最优二叉树

# 性质

假设有n个叶子结点，则由[[二叉树的概念和性质]] 可知，度为2的结点有n-1个，在**哈夫曼树**中，不存在度为1的结点，**只有度为0和度为2的结点**（这样路径最短），所以该哈夫曼树共有2n-1个结点

在**哈夫曼树**中，权值小的结点的路径长度**一定大于**权值大的结点的路径长度

哈夫曼树不唯一
# 算法

如何实现哈夫曼树？

![[哈夫曼算法图解]]
一开始的n个叶子结点认为是n棵树，执行n-1两两合并（保证了n-1个度为2的结点），最终合并成一棵树
合并时，每次选择**权值最小**的两棵树进行合并（保证权值小的结点的路径长度**一定大于**权值大的结点的路径长度），添加一个结点做根结点，这两棵树做该结点的子树（叶子结点），新添加的结点的权值为两个孩子的权值之和
