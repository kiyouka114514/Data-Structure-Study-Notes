# 广度遍历

**层次遍历**，从左到右，从上到下，一层遍历完再到下一层，利用**队列**进行存储，队列内容请前往[[链式队列]]
测试案例
```
7
a
b a 0
c b 0
d b 1
e d 0
f d 1
g e 1
a b c d e f g
```

```cpp
//层次遍历
void LevelOrderBT(BTree root) {
	if (root == NULL) return;
	Queue q = Initqueue();
	enqueue(&q, root->data);

	char x;
	BTNode* p = NULL;
	while (empty(&q) == 0) {
		x = dequeue(&q);
		cout << x << " ";
		p = Find(root, x);
		if (p->l != NULL) enqueue(&q, p->l->data);
		if (p->r != NULL) enqueue(&q, p->r->data);
	}
	cout << endl;
}
```

# 深度遍历

三种：先序遍历、中序遍历、后序遍历
![[Pasted image 20261027161306.png]]

先序遍历： **根**、左、右                         A B D E G C F H I J
中序遍历： 左、**根**、右                         D B G E A C I H J F 
后序遍历： 左、右、**根**                         D G E B I J H F C A

*方法：先写**根**，再写左右，再把新写的当作根，重复进行*

### 递归法
```cpp
//先序遍历
void PreOrderBT(BTree root) {
	if (root == NULL) return;
	cout << root->data << " ";
	PreOrderBT(root->l);
	PreOrderBT(root->r);
}
```
### 非递归法

利用栈的方法——[[链栈]]，将树的结点插入栈中
其中，访问结点的顺序就是**入栈**顺序
```cpp
// 先序遍历
void PreOrderBT(BTree root)
{
    if (root == nullptr)
    {
        cout << "树空，无法遍历" << endl;
        return;
    }
    sstack *top = Initstack();
    BTNode *p = root;
    BTNode *f = nullptr;
    while (p != nullptr || Empty(top)==0)
    {
        if(p!=nullptr){
            cout << p->data << " ";
            Push(top, p);
            p = p->l;
        }
        else{
            f = Pop(top);
            p = f->r;
        }
    }
    cout << endl;
}
```

```cpp
//中序遍历
void InOrderBT(BTree root){
    if(root==nullptr){
        cout << "树空，无法遍历" << endl;
        return;
    }
    sstack *top = Initstack();
    BTNode *p = root;
    BTNode *f = nullptr;
    while(p!=nullptr || Empty(top)==0){
        if (p != nullptr){
            Push(top, p);
            p = p->l;
        }
        else{
            f = Pop(top);
            cout << f->data << " ";
            p = f->r;
        }
    }
    cout << endl;
}
```

### 非递归法

```cpp
void PostOrderBT(BTree root){
    if(root==nullptr){
        cout << "树空，无法遍历" << endl;
        return;
    }
    sstack *top = Initstack();
    BTNode *p = root;
    BTNode *f = nullptr;
    BTNode *pre = nullptr;
    while (p != nullptr || Empty(top) == 0)
    {
        if(p!=nullptr){
            Push(top, p);
            p = p->l;
        }
        else{
            f = Get(top);
            if(f->r!=nullptr && pre!=f->r){
                p = f->r;
            }
            else{
                f = Pop(top);
                cout << f->data << " ";
                pre = f;
            }
        }
    }
    cout << endl;
}
```
