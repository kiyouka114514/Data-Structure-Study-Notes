[[二叉排序树的概念及插入与查找]]

失衡子树：如果一棵子树的根结点失衡，该子树被称为失衡子树
最小失衡子树：以距离插入结点最近的失衡结点为根子树

最小失衡子树的失衡情况分为4种，**LL，LR，RR，RL**
失衡调整要从**最小失衡子树**开始调整
解决办法：
LL,RR——[[平衡二叉树（AVL树）的概念和旋转]]

失衡调整代码
```cpp
// 失衡调整
// LL == 右旋
AVLTree LLrotation(AVLNode *x)
{
    AVLNode *y = x->l;
    // 右旋链接
    x->l = y->r; 
    y->r = x;    
    // 调整高度
    x->h = maxx(Get_h(x->l), Get_h(x->r)) + 1;
    y->h = maxx(Get_h(y->l), Get_h(y->r)) + 1;

    return y; // 返回调整之后的根结点
}
// RR == 左旋 
AVLTree RRrotation(AVLNode *x)
{
    AVLNode *y = x->r;
    // 左旋链接
    x->r = y->l; 
    y->l = x;    
    // 调整高度
    x->h = maxx(Get_h(x->l), Get_h(x->r)) + 1;
    y->h = maxx(Get_h(y->l), Get_h(y->r)) + 1;

    return y; // 返回调整之后的根结点
}
//LR
AVLTree LRrotation(AVLNode* x){
    //先左旋
    x->l = RRrotation(x->l);
    //再右旋
    x = LLrotation(x);
    return x;
}

// RL
AVLTree LRrotation(AVLNode *x)
{
    // 先右旋
    x->r = LLrotation(x->r);
    // 再左旋
    x = RRrotation(x);
    return x;
}
```
